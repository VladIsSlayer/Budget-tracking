# Общая сводка идеи

Для оптимального распределения бюджета зачастую обычному человеку недостаточно одних стараний тратить меньше, получать больше. Есть множество идей и реализаций идеи учета бюджета, но во всех них отсутсвуют два ключевых параметра - удобный учет трат (синхронизация с банком и операциями, проводимыми там), бесплатный доступ. Концептуально идея платить за то, чтобы получать больше является не новой, но крайне противоречивой
